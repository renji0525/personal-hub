# レシート入力モジュール

家計簿の記録フォームへ候補を渡す専用機能です。

- parser.js がOCR文字から日付・合計・店舗・商品を解析し、同じ店舗/商品の過去記録に一意なカテゴリがある場合に候補を返します。
- scanner.js が画像縮小、OCRライブラリの遅延読込、ワーカー、中止・タイムアウトを管理します。
- app.js が専用ダイアログ、画像プレビュー、文字修正、確認・選択反映を扱います。CSSはreceiptDialog内を中心に限定します。
- 家計簿との接点はBudgetReceipt.mount({button, context, apply})です。contextで選択中の保存先・記録・カテゴリを参照し、applyで確認済み候補を入力欄へ渡します。
- 保存は通常の記録フォームから行います。画像やOCR文字を家計簿の保存モデル・同期パケットへ追加しません。

レシート1枚を1件の支出として入力します。複数の商品は商品名とメモへまとめます。日付・合計が分からない場合は確認画面で修正するか、対象項目のチェックを外して元の入力値を使います。使用者は記録フォームで選びます。

## 依存と更新

Tesseract.js 6.0.1のブラウザ本体・workerをvendorに同梱。Apache-2.0のLICENSEと配布時の依存コード表示を同梱しています。取得元はhttps://github.com/naptha/tesseract.js/tree/v6.0.1とnpmの同バージョン配布物です。

読み取り時にjsDelivrからtesseract.js-core 6.0.0と既定の日本語・英語モデルを取得します。file表示ではworkerも同バージョンのCDN配布物を使います。画像はブラウザ内のワーカーで処理します。初回はモデルのダウンロードが必要です。

独立した入力解析テストはtests/receipt.test.cjs、確認画面・保存経路はtests/browser/check-receipt.cjs。RECEIPT_REAL_OCR=1を指定すると架空の日本語レシート画像で実OCRも検証します。実機カメラと実店舗写真での精度は別途確認が必要です。
