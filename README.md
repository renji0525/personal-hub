# personal-hub

共通ログイン、YouTube RSS、家計簿、在庫管理、TODO・買いたいものリスト、メモを備える静的Webアプリです。

## 構成

各ページを `index.html`、`css/style.css`、`js/app.js` に揃えています。

- `web/index.html`：Topへの入口。
- `web/top/`：共通ログイン・登録・ツール一覧。
- `web/youtube-rss/`：RSS一覧、既読管理、JSONバックアップ・復元。同期処理は `js/sync.js`。
- `web/budget/`：家計簿、自由カテゴリ・色、月集計。入力ルールは `js/model.js`、端末保存は `js/store.js`。
- `web/lists/`：TODOと買いたいものの追加・編集・削除・完了/購入済み・検索。入力ルールは `js/model.js`、端末保存は `js/store.js`。
- `web/notes/`：タイトル・本文のメモ、検索・編集・削除。共通モデルと保存処理は `web/lists/js/` を利用し、メモ用データと同期履歴は独立。
- `web/shared/js/auth.js`：共通認証・GAS通信。
- `web/shared/js/budget-spaces.js`：家計簿と在庫の共有スペース・招待・参加・保存先の切り替え。
- `web/shared/css/base.css`：全ページの配色・操作部品。`web/shared/icons/`：ページ別SVG、PNGファビコン、ホーム画面用アイコン。
- `tests/`：Node.js自動テスト。
- `gas/`：GASソース・同期環境（Git対象外）。
- `docs/`、`savedata/`、`tests/browser/`：作業記録・個人バックアップ・このPCのEdge検証（Git対象外）。

旧RSS URL `web/youtube-rss/YoutubeRssFedly.html` は新しい `index.html` へ転送します。

YouTube RSSの追加欄は、UCから始まるチャンネルID、youtube.com/channel/UC…、youtube.com/@ハンドル、@ハンドル単体、旧/user/・/c/形式などのチャンネルURLに対応します。ID形式はそのまま使用し、それ以外はGASでYouTubeの公開チャンネル情報からIDへ変換します。検索結果は1時間キャッシュ。同じIDは重複登録せず、解決失敗時は入力を保持します。追加APIキーや外部検索ツールの登録は不要です。

## パスワードを忘れた場合

ホームの「パスワードを忘れた方」から一時ログインし、新しいパスワードを設定できます。管理者はユーザー情報Googleスプレッドシートの「一時パスワード用シート」へ、A列「ユーザー名」に登録済みユーザーID、B列「一時パスワード」に8〜128文字を手入力します。再設定が完了すると該当行を削除し、そのユーザーの古いログインを無効化します。一時ログインでは再設定のみ可能です。

## 起動と検証

`web/index.html` をブラウザで開きます。ビルド不要です。クラウド同期にはGASと共通ログインを使用します。

```powershell
node --test tests/*.test.cjs
node --check web/shared/js/auth.js
node --check web/top/js/app.js
node --check web/youtube-rss/js/app.js
node --check web/youtube-rss/js/sync.js
node --check web/budget/js/app.js
```

## 保存・通信

ログイン情報をlocalStorageに保存し、最大30日間保持します。パスワードは保存しません。画面表示時は端末の有効期限を確認し、各データAPIでサーバー認証します。ログアウトは端末を即時解除し、サーバーへの無効化要求も送ります。通信失敗時は端末側だけの解除になります。

RSSはユーザー別の全件キャッシュを先に表示し、起動時に同期。通常は認証を含め1APIです（旧既読移行・100件超の既読送信は追加通信）。表示・絞込・既読・バックアップは通信なし。既読は次回同期でまとめて送信し、ログアウト時も未送信キューを維持します。「更新」は各チャンネルのRSS取得と最後の同期を行います。

家計簿はユーザー別に端末保存し、ページを開いた時と「同期する」でのみ同期します。未同期操作は20件ずつ送信。変更がない時は更新番号だけ返し、記録シートの読込と全データ転送を省きます。別端末との競合時は未同期内容を保持して停止します。サイトデータを削除すると未同期分も消えるため、必要ならJSONバックアップを利用してください。

自動同期は日本時間の0～12時・13～18時・19～23時の各日各時間帯の初回表示です。手動同期はいつでも利用できます。

## 家計簿・在庫・リストの共有

家計簿・在庫の「共有の設定」でスペースを作成し、登録済みのユーザーIDを招待します。相手は自分の「共有の設定」から「参加する」を押し、「このスペースを使う」で切り替えます。家計簿と在庫・カテゴリはセットで共有し、参加者全員が閲覧・追加・編集・削除できます。招待・参加者の解除は所有者が行い、参加者は退出や招待辞退ができます。

リストも同じ共有スペース・参加権限を使います。既存スペースに参加済みなら追加の招待は不要です。個人用との切替も共通ですが、リストの端末保存・同期・更新番号は家計簿/在庫から独立しています。

メモも同じ共有スペースで共同編集できます。既存メンバーは追加招待不要で、個人用のメモは共有されません。

家計簿・在庫・リスト・メモは、上部の「個人用」と参加中の共有スペースごとのタブで切り替えられます。招待中は承認後にタブへ追加されます。共有一覧はユーザー別に端末保存し、各時間帯の初回表示、または「タブを更新」で取得。共有の作成・参加・退出も即時に反映します。タブ切替はページを再表示しますが、保存済みの未同期データは元の保存先に残ります。

選択中のタブは家計簿・在庫・リスト・メモで別々に記憶します。他のページのタブを切り替えても、そのページの選択は変わりません。以前の共通選択は各ページの初回だけ引き継ぎます。ホームと家計簿の補充お知らせは、在庫管理で選んだ保存先を表示します。

新しい共有スペースは空のデータと標準カテゴリで開始します。個人用データは移動・合算せず保持します。端末データと同期履歴はユーザー・スペースごとに分け、切替前の未同期内容も元の場所に残します。他の人の変更は同期後に反映され、競合時は未同期内容を残して停止します。

共有の参加権限はデータAPIごとに確認します。解除の検出は次回通信時です。オフラインや同時間帯の再表示では、取得済みの端末キャッシュを利用できます。共有管理には通信が必要です。スペース自体の削除・所有者変更・個人データのコピー機能はありません。

GASはユーザー情報、RSS、家計簿を別スプレッドシートで管理。既存DBの分離は `setupSplitDatabases` を使用します。手順はローカルの `gas/README.md`、現在の状態は `docs/STATUS.md`、家計簿の使い方は `docs/BUDGET.md` を参照してください。

家計簿は記録を50件ずつ表示し、集計を再利用します。キャッシュがある場合は初回取得の応答待ち中も編集でき、編集内容は保持して次回同期へ回します。同じ記録の連続保存は未送信部分だけ最終値に集約。RSSのテーマ・絞込変更は表示設定だけを保存します。

## 在庫管理

ホームまたは家計簿から「在庫管理」を開き、商品名・前回購入日・補充までの日数・何日前から知らせるかを登録します。例えば30日間隔・3日前なら、購入から27日後にお知らせが表示されます。

「購入を記録」で次の目安日を更新できます。購入金額を入力すると家計簿に支出を追加し、空欄なら購入日だけ更新します。家計簿に入力済みの場合は空欄にしてください。商品の削除は家計簿の支出を削除しません。

お知らせは保存済みデータからホーム・家計簿・在庫画面に表示します。ページを閉じている時の通知はありません。編集時の通信はなく、起動時・同期ボタンで家計簿とまとめて同期。他端末の変更は同期後に反映されます。

ページは web/inventory/、お知らせは web/shared/js/inventory-reminders.js、アイコンは web/shared/icons/inventory.* とPNG。GASは家計簿DBにBudgetProductsを自動追加します。

## TODO・買いたいものリスト

ホームまたは共通ヘッダーの「リスト」から開きます。TODOはタイトル・期限・メモ、買いたいものはタイトル・商品リンク・メモを保存できます。チェックで完了/購入済みを切り替え、未完了・すべて・完了の絞込や検索も利用可能です。各リストは50件ずつ表示し、合計1000件まで保存できます。

追加・編集画面の「担当ユーザー」で共有スペースの参加者を選ぶと、一覧に担当者を表示します。未指定も選べ、個人用では自分だけを選択できます。新しい参加者が候補にない場合は「担当者一覧を更新」を押してください。既存の担当なしデータも利用できます。

間違えて完了・購入済みにした直後は「元に戻す」で取り消せます。後からは表示を「完了・購入済み」に切り替え、「未完了に戻す」「未購入に戻す」を押します。同期後でも戻せて、担当者やメモは保持します。

編集は端末保存、自動同期は日本時間の各時間帯初回、手動同期はいつでも可能です。未同期内容は再読込・個人/共有切替後も元の場所に保持。競合時はバックアップ後に未同期変更を破棄・再取得できます。購入済みにしても支出や在庫へは自動追加しません。JSON書出しに対応し、復元UI・通知はありません。

GASは既存家計簿DBにListsUsers・ListItemsを追加するスキーマ5。listsLoad/listsSyncは既存共有スペースの参加権限を確認します。入力モデルの生成はnode gas/scripts/build-lists.cjsです。

## メモ

ホームまたは上部の「メモ」から開き、「メモを書く」で保存します。タイトルは任意（空欄なら本文の先頭を使用）、本文は5000文字まで。タイトル・本文の検索、編集・削除、JSONバックアップ、50件ずつの表示に対応。

個人用と共有スペースを切り替えて利用できます。保存した内容は端末に保持し、日本時間の各時間帯初回と手動で同期。メモのデータ・更新番号・同期履歴はTODO/買いたいものから独立し、既存の同時編集統合・再送重複防止を再利用します。自動下書き保存・書式編集・画像添付・JSON復元UIはありません。
